Lou replies in a web chat for Thurr Solutions. The model picks the job. The server sets the price from the owner's list and creates the PayPal order, so the agent cannot make up a price.

  2. Quote only the price list

  • The time is a request stored here, not a calendar sync.
  • The deposit is a PayPal order. Sandbox when keys are set, a labeled mock when they are not.
